# Контроль качества звонков из Битрикс24

Демо-проект для отдела продаж: система сама выгружает звонки из Битрикс24, расшифровывает записи, оценивает каждый разговор по чек-листу скрипта продаж и готовит отчёт руководителю.

Руководителю не нужно слушать часы записей. Утром у него в Telegram лежит сводка: кто из менеджеров как работает, какие пункты скрипта проседают, и Excel с разбором каждого звонка.

## Что умеет

- **Выгрузка звонков** из Битрикс24 за любой период (`voximplant.statistic.get`): менеджер, клиент, тип, длительность, статус, привязка к лиду или сделке.
- **Расшифровка записей** через API распознавания речи (Whisper и совместимые).
- **Оценка по чек-листу.** Пункты и веса задаются в `checklist.toml` под скрипт конкретной компании.
  - **Нейросеть** отмечает каждый пункт с комментарием, пишет итог звонка, рекомендации менеджеру и настроение клиента.
  - **Без нейросети** оценка идёт по ключевым фразам: бесплатно, для демо и как запасной режим.
  - Итоговый балл считает код по весам, а не нейросеть, поэтому оценка воспроизводима.
- **Пропущенные и короткие звонки** учитываются отдельно и не портят статистику.
- **Отчёт Excel из трёх листов:**
  - сводка по отделу;
  - рейтинг менеджеров со «слабым местом» каждого;
  - разбор каждого звонка с цветовой разметкой и ссылкой на карточку CRM.
- **Оценка в карточке CRM:** запись в таймлайн лида или сделки (`--write-back`).
- **Сводка и файл в Telegram** руководителю (`--telegram`).
- **Кэш:** повторный запуск не платит за уже расшифрованные и оценённые звонки. Если поменять чек-лист, звонки переоценятся автоматически.
- **Устойчивость:** ошибка на одном звонке не ломает отчёт, а лимиты запросов Битрикс24 соблюдаются.

## Попробовать без Битрикса

В папке `demo/` лежат 8 вымышленных звонков онлайн-школы «Пиксель». Среди них хорошие и плохие разговоры, а также пропущенный и короткий звонок.

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python -m callqa --demo --out reports/demo.xlsx
```

Готовый результат демо-запуска лежит в `demo/demo_report.xlsx`.

С оценкой нейросетью (нужен ключ API в `.env`):

```bash
python -m callqa --demo --evaluator llm --out reports/demo_llm.xlsx
```

## Работа с реальным Битрикс24

1. В Битрикс24 создайте входящий вебхук: **Разработчикам → Другое → Входящий вебхук**. Права: `telephony`, `user`, `disk`, `crm`.
2. Скопируйте `.env.example` в `.env` и заполните адрес вебхука, ключ нейросети и модели.
3. Настройте `checklist.toml` под скрипт продаж компании.
4. Запустите:

```bash
# вчерашние звонки (по умолчанию)
python -m callqa

# за период, с записью оценок в CRM и отправкой руководителю
python -m callqa --from 2026-11-01 --to 2026-11-08 --write-back --telegram

# только один менеджер
python -m callqa --from 2026-11-01 --to 2026-11-08 --manager Волков
```

Для ежедневного отчёта добавьте запуск в планировщик (cron или Планировщик заданий Windows), например каждое утро в 8:00:

```
0 8 * * * cd /opt/calls-qa && venv/bin/python -m callqa --telegram
```

### Настройки (`.env`)

| Параметр | Что это |
|---|---|
| `BITRIX_WEBHOOK` | адрес входящего вебхука `https://<портал>.bitrix24.ru/rest/<id>/<ключ>/` |
| `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` | нейросеть для оценки (OpenAI-совместимый API) |
| `STT_MODEL` | модель распознавания речи; без неё звонки без готовой расшифровки пропускаются |
| `STT_API_KEY`, `STT_BASE_URL` | если распознавание у другого провайдера (по умолчанию как у LLM) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | куда отправлять сводку |

## Как устроено

```
callqa/
  bitrix.py      — Битрикс24 REST: звонки, сотрудники, записи, комментарии в CRM
  transcribe.py  — расшифровка аудио
  evaluate.py    — чек-лист, оценка нейросетью и по ключевым фразам
  pipeline.py    — конвейер: запись → текст → оценка, кэш, причины пропуска
  report.py      — Excel-отчёт и текстовая сводка
  notify.py      — отправка в Telegram
  cache.py       — кэш расшифровок и оценок
checklist.toml   — чек-лист скрипта продаж (меняется без программиста)
demo/            — вымышленные звонки для демонстрации
tests/           — тесты без сети: Битрикс, нейросеть и Telegram заменены заглушками
```
